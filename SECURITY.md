# Security policy

## Supported versions

Only the latest release receives security fixes.

| Version | Supported |
| ------- | --------- |
| latest  | yes       |
| older   | no        |

Replace this table when the project maintains several release lines.

## Reporting a vulnerability

Do not open a public issue.

Report privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. If that is not available, email `hello@sebbejohansson.com`.

Include:

- What is affected, and which version.
- Steps to reproduce, or a proof of concept.
- The impact you expect.

## What to expect

- Acknowledgement within 7 days.
- A fix or a decision within 90 days. You will be told which.
- Credit in the release notes, if you want it.
